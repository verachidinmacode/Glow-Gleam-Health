# Glow & Gleam Health 

**Your health. Your wellness. Your glow.**

Glow & Gleam Health is a Java-based healthcare and wellness management application designed to help users organize basic health information and track daily wellness activities.

This project is currently a work in progress as I continue developing my Java programming skills and exploring healthcare technology.

##  Features

- **My Health:** Enter and view a basic health profile.
- **Vitals:** Record and display heart rate information.
- **Appointments:** Enter and organize appointment details.
- **Medications:** Record medication names, dosages, and schedules.
- **Wellness:** Track daily water intake, sleep, and exercise.
- **Input Validation:** Check for invalid age entries.

##  Getting Started

1. Clone this repository:

   ```bash
   git clone https://github.com/verachidinmacode/Glow-Gleam-Health.git
   ```

2. Open the project folder in Visual Studio Code.
3. Compile the Java file:

   ```bash
   javac Main.java
   ```

4. Run the application:

   ```bash
   java Main
   ```
